Pay for learning, not attendance

Kratu Learning Fund

Donations sit in a pool on NEAR and are released to a learning centre only when children there master English items in Kratu, an offline Hausa-first tutor. Everything below is read live from the contract.

Fund learning

Connect a NEAR wallet to donate. Funds are released only as children master items.

Check a learner

Learners are opaque IDs. No names or faces are ever stored on-chain.

How it works

  1. Donors fund the poolAnyone can donate. Funds stay in the contract.
  2. Children learnKratu measures mastery from what each child says.
  3. Oracle reportsA sync service sends each learner's running total.
  4. Centre is paidEvery 50 newly mastered items releases a payout, never twice.
Demo data Learner progress comes from a mock feed shaped like Kratu's pilot records. Not affiliated with or endorsed by Kratu. Built for the NEAR Hackathon.
